## 화면 인식 보정과 하단 화면 미리보기
맥 제목 표시줄과 Retina 확대 때문에 창 높이로 추정한 글자 배율이 어긋나는 경우를 보정했습니다.
글자 배율을 별도로 찾고, 넓은 창의 경험치 영역도 글자 픽셀 간격에 맞춰 읽습니다.
인식 영역 탭에 실제 캡처한 하단 화면, 캡처 크기, 인식한 배율을 표시합니다.
인식 실패 시 진단용 하단 화면을 사용자가 직접 PNG로 저장할 수 있습니다. 자동 저장·전송은 없습니다.
게임 창을 선택한 뒤 인식 영역 탭의 여백을 우선 0%로 되돌려 확인하세요.
기존 게임 이미지와 제목 표시줄/확대 조건을 적용한 회귀 검사를 통과했습니다. 제보한 Mac 실기기에서의 해결 여부는 확인 전입니다.

## Ventura 호환
기존 맥판은 macOS 14 이상용이어서 Ventura에서 실행할 수 없었습니다.
이번 빌드는 macOS 13부터 로드할 수 있는 Qt 6.8.3과 라이브러리를 사용합니다.
Ventura는 선택한 게임 창을 CoreGraphics로, macOS 14 이상은 ScreenCaptureKit으로 캡처합니다.
앱과 포함된 Mach-O 라이브러리의 최소 macOS 버전도 검사합니다.
Ventura 실기기에서의 실행·게임 인식 검증은 사용자 확인 전이며, 자동 실행 테스트 환경은 macOS 15입니다.

메소 +α 표시와 레벨업 예상 시간이 추가되었습니다.

macOS 13 이상용 테스트 버전입니다. Windows 정식 배포와 별도입니다.

## 검증 범위
- macOS Apple Silicon 및 Intel 환경에서 빌드, 단위 테스트, 캡처 API 존재 확인, 완성된 앱 시작·그리기 테스트를 실행합니다. 두 빌드가 통과해야 이 릴리스가 게시됩니다.
- 실제 CrossOver 게임 인식, 전역 단축키 입력, Retina/전체 화면/다중 모니터 동작은 실기기 확인 전입니다.
- 화면은 메모리에서 처리합니다. 진단용 하단 PNG는 사용자가 저장 버튼을 누를 때만 저장하며, 자동 전송하거나 오디오를 캡처하지 않습니다.

## 서명 상태
Apple Developer ID 서명 및 공증을 받지 않은 테스트 빌드입니다. 무결성용 ad-hoc 서명은 Apple 배포용 인증과 다릅니다. Gatekeeper가 차단할 수 있으며 일반 사용자 배포를 위한 서명·공증은 아직 남아 있습니다.
보안 기능을 끄거나 격리 속성을 지우는 명령으로 우회하지 마세요. 차단되면 정확한 문구를 알려 주세요.

메소 표시 옆 +α: 인식하지 못한 획득량이 더 있을 수 있습니다. 실제 누락량은 알 수 없어 숫자에 더하지 않습니다.
레벨업까지 남은 시간: 남은 경험치 / 측정 중 평균 순 경험치 속도. 인식 실패·경험치 획득 속도 없음·최고 레벨은 —로 표시합니다. 표시 항목에서 켜고 끌 수 있습니다.
