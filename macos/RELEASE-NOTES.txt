메소 +α 표시와 레벨업 예상 시간이 추가되었습니다.

macOS 14 이상용 테스트 버전입니다. Windows 정식 배포와 별도입니다.

## 다운로드
- [Apple Silicon (M 시리즈)](https://github.com/Kyle0327/maple-meter-checker/releases/download/mac-v2.2.0-preview.2/MapleMeterChecker-macOS-arm64-preview.zip)
- [Intel Mac](https://github.com/Kyle0327/maple-meter-checker/releases/download/mac-v2.2.0-preview.2/MapleMeterChecker-macOS-x86_64-preview.zip)

ZIP을 풀고 MapleMeterChecker.app을 응용 프로그램 폴더로 옮겨 실행합니다.
화면 기록 권한을 허용하고 앱을 다시 연 뒤, CrossOver 게임 창을 선택하세요.
자세한 설명과 기본 단축키는 README-mac.txt를 확인해 주세요.

## 검증 범위
- macOS Apple Silicon 및 Intel 환경에서 빌드, 단위 테스트, 캡처 API 존재 확인, 완성된 앱 시작·그리기 테스트를 실행합니다. 두 빌드가 통과해야 이 릴리스가 게시됩니다.
- 실제 CrossOver 게임 인식, 전역 단축키 입력, Retina/전체 화면/다중 모니터 동작은 실기기 확인 전입니다.
- 화면은 메모리에서만 처리하고 이미지나 오디오를 저장·전송하지 않습니다.

## 서명 상태
Apple Developer ID 서명 및 공증을 받지 않은 테스트 빌드입니다. 무결성용 ad-hoc 서명은 Apple 배포용 인증과 다릅니다. Gatekeeper가 차단할 수 있으며 일반 사용자 배포를 위한 서명·공증은 아직 남아 있습니다.
보안 기능을 끄거나 격리 속성을 지우는 명령으로 우회하지 마세요. 차단되면 정확한 문구를 알려 주세요.

메소 표시 옆 +α: 인식하지 못한 획득량이 더 있을 수 있습니다. 실제 누락량은 알 수 없어 숫자에 더하지 않습니다.
레벨업까지 남은 시간: 남은 경험치 / 측정 중 평균 순 경험치 속도. 인식 실패·경험치 획득 속도 없음·최고 레벨은 —로 표시합니다. 표시 항목에서 켜고 끌 수 있습니다.
