Maple meter checker — macOS 테스트 버전
버전: 2.2.0-mac-preview.1

지원 대상
- macOS 14 이상, Apple Silicon 또는 Intel Mac (해당 CPU용 ZIP 선택)
- CrossOver 등에서 실행한 메이플스토리 클래식 월드 게임 창
- 게임 설치나 실행 환경을 제공하는 프로그램은 아닙니다.
- 실제 CrossOver 게임 화면 인식·전체 화면·단축키는 맥 사용자 테스트가 필요합니다.

설치와 시작
1. 자신의 Mac CPU에 맞는 ZIP을 다운로드하고 압축을 풉니다.
2. MapleMeterChecker.app을 응용 프로그램 폴더로 옮깁니다.
3. 앱을 열고 '화면 기록 권한'을 누릅니다.
4. macOS 시스템 설정에서 화면 기록 권한을 허용하고 앱을 다시 엽니다.
5. CrossOver에서 게임을 창 모드로 실행합니다.
6. '창 목록 새로고침'을 누르고 게임 창을 선택합니다.
7. 경험치 인식이 확인되면 '측정 시작'을 누릅니다.

보안 서명
이 테스트 빌드는 Apple Developer ID 서명 및 공증을 받지 않았습니다.
내부 무결성 확인용 ad-hoc 서명은 Apple의 배포용 서명과 다릅니다.
Gatekeeper가 앱을 차단할 수 있습니다. 차단 문구를 확인해 제작자에게 알려 주세요.
보안 기능을 끄거나 격리 속성을 제거하는 명령을 사용하지 마세요.
경고 없이 일반 사용자에게 배포하려면 Developer ID 서명·Apple 공증이 필요합니다.

기능
경험치/메소 각각 누적, 분당, 30분, 1시간 + 측정 시간.
경험치 수치/% 전환, 별도 배경·글자 불투명도, 볼드 흰색 글자와 검정 테두리.
게임 밖·다른 모니터로 패널 이동, 배경 0%에서 이동 손잡이 유지.
초기화 후 8초 이내 취소 가능. 메소 메시지 누락 가능성은 설정 화면에 표시.

기본 단축키 (Alt는 Mac의 Option 키)
Control + Option + S: 시작/일시정지
Control + Option + O: 설정 열기
Control + Option + L: 위치 잠금/클릭 통과
Control + Option + R: 초기화
Control + Option + E: 경험치 수치/% 전환
설정 화면에서 Cmd, Ctrl, Alt, Shift와 A–Z/F1–F11 조합으로 변경할 수 있습니다.
단축키가 충돌하면 다른 조합을 선택하세요. 화면 버튼도 사용할 수 있습니다.

인식이 안 될 때
- 게임 창을 최소화하지 마세요.
- 창 제목 표시줄이나 검은 여백이 포함되면 '인식 영역' 탭에서 제외 여백을 조절하세요.
- 영역 변경은 현재 측정을 일시정지합니다. 다시 인식된 다음 측정을 재개하세요.
- Retina 배율, 게임 해상도, CrossOver 버전에 따라 추가 보정이 필요할 수 있습니다.
- Windows에서 확인한 이미지 인식 규칙을 재사용합니다. 다른 게임 버전은 검증하지 않았습니다.
- 화면에서 사라진 메소 메시지는 복구할 수 없습니다.

개인정보
사용자가 선택한 창만 캡처하며 오디오를 캡처하지 않습니다.
화면은 메모리 안에서 처리하며 이미지 저장·서버 전송·계정 로그인이 없습니다.
설정은 ~/Library/Application Support/MapleMeterChecker/settings.json에 저장합니다.
앱을 종료하면 측정값은 초기화됩니다. Nexon의 공식 앱이 아닙니다.
